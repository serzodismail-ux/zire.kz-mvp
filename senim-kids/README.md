# Senim Kids

Интерактивный MVP веб-приложения Senim Kids: детский кабинет с играми, AAC-карточки, родительский кабинет, панель специалиста, прогресс, награды и сохранение демо-данных в `localStorage`.

## Запуск

Откройте `index.html` в браузере. Для GitHub Pages дополнительных сборщиков не нужно: сайт работает как статический SPA.

## Структура

- `index.html` - оболочка приложения.
- `styles.css` - адаптивный дизайн, карточки, панели, игровые состояния.
- `app-*.js` - маршрутизация, игры, localStorage, награды, заметки, назначения специалиста.
- `assets/hero-senim-kids.jpg` - hero-иллюстрация.

## Реализовано

- Главная страница продукта.
- Режимы: ребенок, родитель, специалист.
- 5 развивающих заданий: эмоции, слова, внимание, социальные истории, AAC-карточки.
- Начисление звезд, уровни, streak и награды.
- Родительские заметки с сохранением.
- Назначение заданий специалистом.
- Отображение прогресса и имитация AI-анализа.
- Адаптивный интерфейс для телефона и ноутбука.

## Моковые данные

Профиль ребенка, недельный прогресс, список детей специалиста, рекомендации и задания пока моковые. Состояние демо сохраняется в `localStorage`.
